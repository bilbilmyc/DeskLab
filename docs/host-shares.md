# 宿主目录共享

把本机文件夹按实例共享给虚拟机，在系统内浏览、下载和上传文件。这是**文件通道**，不是挂载盘：虚拟机里看到的是 HTTP 地址，不是新的盘符或挂载点。技术选型见 [宿主共享调研](plans/host-share-and-driver-delivery-research.md)。

## 使用步骤

1. 在「测试环境」列表中打开实例的「更多操作 → 宿主目录共享」。
2. 填写共享名称（字母或数字开头，可含点、下划线、连字符，最长 32 位），选择本机文件夹；勾选「只读」可禁止虚拟机上传。
3. 启动环境后，面板中会出现带令牌的访问地址，用「复制下载命令」或「复制上传命令」把命令粘贴到系统内执行。

共享随实例记录保存，重启 DeskLab 和虚拟机后仍有效。删除共享只解除访问，宿主文件夹和文件都会保留。

## 系统内怎么访问

地址只在虚拟机的 NAT 网络内可达（`10.0.2.2` 即宿主），且令牌就是全部权限。命令中的 `端口` 和 `令牌` 以实例面板显示为准。

Linux（Ubuntu / Debian / Rocky 等自带 curl）：

```bash
curl http://10.0.2.2:端口/share/令牌/名称/          # 浏览：返回 JSON 文件列表
curl -O http://10.0.2.2:端口/share/令牌/名称/文件名  # 下载到当前目录
curl -T 文件名 http://10.0.2.2:端口/share/令牌/名称/ # 上传宿主文件夹根目录
```

Windows 10 / Server（使用系统自带的 curl.exe；PowerShell 里必须写 `curl.exe`，不能写 `curl`）：

```powershell
curl.exe http://10.0.2.2:端口/share/令牌/名称/
curl.exe -O http://10.0.2.2:端口/share/令牌/名称/文件名
curl.exe -T 文件名 http://10.0.2.2:端口/share/令牌/名称/
```

浏览结果中的 `entries` 列出文件和子文件夹（含大小），可以直接拼接在地址后继续访问子目录。

## 限制与边界

- 上传只支持共享文件夹根目录下的普通文件名，单个文件最大 4 GB；不能覆盖已有文件夹或链接。
- 只读共享会拒绝上传；删除共享或关闭环境后，地址立即失效。
- DeskLab 数据目录本身不能共享，以避免暴露实例磁盘和元数据库。
- 通道随环境运行而监听，随环境关闭而停止；宿主目录映射为虚拟机盘符（挂载式共享）暂不支持。

## 安全模型

- 通道只绑定本机回环 `127.0.0.1`，虚拟机经 NAT 网关 `10.0.2.2` 访问；局域网和其他主机不可达。
- 请求校验 Host 和 Origin，跨站页面无法读取响应；令牌为 256 位随机值，随实例保存在本机数据库。
- 路径逐段校验：拒绝 `..`、反斜杠、控制字符、Windows 保留设备名和结尾点/空格，访问不会越出共享文件夹。
- 令牌即权限：任何拿到地址的一方都能读取（可写共享还能上传）共享文件夹中的全部内容，请勿粘贴到不信任的位置。
