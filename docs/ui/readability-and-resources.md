# 可读性与模板资源 · 0.3.3

系统模板创建窗口直接显示处理器、内存和磁盘配置，位于网络配置之前。CPU 支持整数核数，内存使用 MB，磁盘使用 GB；限制仍由服务端校验，自动安装保留相应系统的最低内存与磁盘要求。更改只作用于新副本，不更改系统模板或其他实例。

已准备好的模板允许创建相同或更大容量的虚拟磁盘，拒绝缩小。仅创建独立 qcow2 副本，不修改基盘；恢复初始状态时仍保留实例分配的磁盘容量。扩大虚拟磁盘并不自动扩大客体分区，需进入系统检查并扩展分区、卷与文件系统：[QEMU 镜像工具文档](https://www.qemu.org/docs/master/tools/qemu-img.html)。

全局正文采用 500 字重，标签和操作提高到 600；次级文字加深，卡片边框提高到 2 个 CSS 像素，部分辅助文字增加到 12–13px。使用统一 CSS 尺寸与响应布局，不按显示器分辨率直接设置整页缩放。Windows 显示缩放、浏览器缩放与字体渲染共同影响物理屏幕上的实际大小。
