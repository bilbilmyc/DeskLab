# 全局工作台界面 · 0.3.2

以 Docker 工作台为基准统一测试环境、模板库、本机设置、端口映射和系统控制台。面向本机测试系统的创建与使用，不增加监控仪表盘。

## 设计规则

沿用钴蓝 `#2457e6`、深色文字 `#202638`、次级文字 `#697386`、背景 `#f8f9fc`、白色资源区 `#ffffff` 和分隔线 `#e2e6ef`。页面标题使用 Bahnschrift / 微软雅黑，操作和正文使用 Segoe UI / 微软雅黑，端口与路径使用 Cascadia Code / Consolas。标题、工具栏、资源区、辅助说明采用不同密度。

页面标题、分类、搜索和主操作保持固定；长内容在各自区域滚动。蓝色状态条表示宿主资源或存储位置。帮助说明和低频配置折叠，维护操作通过明确入口打开；危险操作沿用原有确认流程。

## 页面变化

- 测试环境：紧凑资源条、名称与状态筛选、按行显示 CPU/内存/磁盘和 SSH 入口。启动、打开系统、正常关机和连接直接可见；保存模板、恢复、强制关闭、弹出 ISO 和删除归入“更多操作”。
- 模板库：固定来源分类与搜索，支持只看“已准备好”的模板。绿色标记表示可直接创建；搜索到其他 Linux 桌面模板时自动展开所在分组。登录和管理功能仍通过详情进入。
- 本机设置：固定设置分类。ISO 以列表展示，目录管理折叠；下载进度和异常保留。运行与存储分别展示硬件、引擎检测、文件位置，高级引擎配置按需展开。
- 端口映射：固定分类和搜索，突出本机入口、目标与资源状态。桌面使用表格，窄窗口改为逐条排列。复制、编辑、删除和映射说明继续可用。
- 系统控制台：统一外边距与工具栏密度，保留可用画面高度、SSH 信息和连接状态。
