# 第一次使用 DeskLab

> 当前为预发布版本。GitHub Actions 默认提供不含独立 Docker Linux 组件的基础安装包；完整构建的区别见 [README](../README.md#下载与安装)。

DeskLab 让你在浏览器里打开一台独立的 Windows 或 Linux 测试电脑。先双击 `DeskLab-Setup.exe`，选择安装目录并完成安装，再打开 DeskLab 快捷方式或 `DeskLab.exe`。浏览器会自动打开。

安装器会自动创建 `data`、`iso` 和 `templates` 目录，不需要复制开发项目的 `.data`。`iso` 起初为空，用来存放之后选择或下载的安装盘；`templates` 放使用说明，真正安装好的系统会保存在 `data` 中。

## 先创建一个环境

1. 点击「创建环境」。
2. 在「系统自带」里选择 Ubuntu Server、Debian Server、Rocky Server、Windows 10 或 Windows Server，点击「下一步」。前三种打开终端，Windows 打开桌面。
3. 首次使用时，在「原版 ISO 安装盘」选择对应版本的文件；没有文件就点击「没有安装盘？前往下载 ISO」，按下面的步骤准备。给环境起个名字，例如「Bun 测试」；不清楚内存和 CPU 怎么选时，保持默认值。
4. 点击「创建并自动安装」，保持 DeskLab 运行，等待自动安装完成。程序会配置账号，在系统正常关机后保存基础系统，再自动进入终端或桌面。
5. 以后创建同类环境时，模板显示「已准备好」，点击「创建并启动」即可，不需要 ISO 或重复安装。

每个环境都有自己的修改记录。你可以从同一个模板创建多个环境，分别进行测试。测试环境页面只有环境列表滚动，导航、标题、资源统计和筛选栏保持固定。

创建窗口直接显示 CPU、内存和磁盘配置，名称/ISO 与资源在桌面端并排排列，底部操作固定。基于已有模板的磁盘容量不能缩小；扩大后可能需要在客体中扩展分区。

ISO 可以放在应用目录之外。选完后查看系统识别结果：选错时不能创建，可以更换文件或切换安装配置；未知自定义镜像确认类型后可手动安装。完整规则见 [ISO 与系统支持](iso-guide.md)。

关机时点击实例电源按钮，会先显示实例名称并要求“确认关机”；取消、关闭窗口或按 Esc 不会发送关机请求。安装未完成时会另外提醒。发送成功后等待系统退出，不要把“请求已发送”当作已关机。

上述五套系统自动安装后会自动登录。需要手动登录时，Windows 使用 `Administrator`，Linux 使用 `root`，密码都是 `DeskLab0987`。自己导入或手动安装的系统使用原来设置的账号密码；导入动作不会替你更改密码。安装中请勿关闭 DeskLab 或强制停止环境；强制中断后可能需要重新创建。

Linux 桌面版收在「其他 Linux 桌面模板」中，目前需要使用已有的已安装系统，或手动安装。已有配套的已安装磁盘时，在模板库找到对应的系统卡片，点击「详情 → 导入已安装的系统磁盘」。当前支持下载 ISO 安装盘，尚不支持在线下载已安装好的模板磁盘。

## 找不到系统时，准备安装盘

先打开左侧的 **「本机设置」**，选择顶部的 **「系统镜像」** 分组。另一个「运行与存储」分组用于查看运行引擎、本地存储和首次使用帮助。

1. 在「ISO 存放目录」卡片中点击「选择文件夹」，选择专门存放安装盘的文件夹，例如 `D:\DeskLab-ISO`。也可以直接保留界面中的默认目录。
2. 更改目录后点击「保存并扫描」；使用原目录时点击「重新扫描」。保存后立即生效，不需要重启程序。
3. 找到想使用的系统安装盘卡片。如果显示「已在本地」，点击「启动安装」。如果没有对应文件，点击「在线下载」。
4. 下载时会显示进度、已下载大小、速度和剩余时间。你可以切换到其他页面；需要停一下时点「暂停」，准备好后点「继续下载」，失败后可点「重新下载」。
5. 下载完成后点击「启动安装」。如果窗口提示「已匹配自动安装模板」，给环境起名并点击「创建并自动安装」；否则点击「开始安装」，按原系统安装向导设置账号，完成后正常关机并「保存为模板」。

**ISO 就像系统安装 U 盘，下载 ISO 不等于下载系统磁盘。** 程序里的小型安装模板负责替支持的系统完成首次安装和登录配置；其他 ISO 仍需你按向导安装。模板库标记「已准备好」的系统已经装好，可以直接创建环境，不需要重复下载 ISO。

关闭 DeskLab 后下载会暂停，下次打开时手动点击「继续下载」。有些下载站不支持可靠续传，继续时可能会从头下载。更换目录前，请先暂停下载中、校验中和排队的任务；更换目录不会把已有文件自动搬过去。

如果你已经有 ISO，把它放进指定目录再点击「重新扫描」。程序会按文件名和大小识别内置系统；其他名称的 ISO 会列在「目录中发现的其他 ISO」。本地扫描不校验整张镜像；首次自动安装会另行检查对应版本的大小和官方 SHA256，Windows Server 没有公开官方哈希，只检查大小并记录本地校验值。原版 ISO 不会被修改。点击安装盘卡片上的「文件与来源」，可在弹窗中查看文件名、位置及校验说明。也可以直接使用「从 ISO 安装」入口选择文件。

## 把自己的配置变成模板

模板就是一份可以反复使用的系统底稿。例如，你可以做一个已经装好 Bun 和 Git 的 Debian 模板：

1. 从 Debian 模板创建环境，在里面安装 Bun、Git，并完成自己的设置。
2. 从 Debian 系统内正常关机，等待 DeskLab 显示环境已停止。
3. 回到「测试环境」，对这个环境点击「保存为模板」。
4. 填写名称，例如「我的 Bun 开发环境」，然后保存。说明可以选填；需要调整资源或记录账号时，再展开「默认资源与登录说明」。
5. 下次打开「创建环境 → 我的模板」，选它并点击「下一步」，起好名字后点击「创建并启动」。

「模板库 → 我的模板」以卡片展示已保存的模板。点击「详情」打开管理窗口，再点击「编辑模板信息」修改名称、说明、默认资源和登录说明；「删除这个模板」也在该窗口中。编辑说明文字不会替你修改系统密码；需要更换软件或系统配置时，先创建一个环境，在系统内修改并关机，再保存为模板。

## 已有 ISO 或虚拟磁盘

- **ISO 是安装盘**：在「创建环境」点击「已有 ISO 安装盘？从 ISO 安装」，再点击「下一步」。选取文件并填写名称。窗口提示已匹配自动安装模板时，可「创建并自动安装」；其他 ISO 点「开始安装」并按照系统安装向导操作。手动安装完成并正常关机后，保存为自己的模板，DeskLab 会卸下安装盘，下次直接进入已安装的系统。首次自动安装最方便的入口是「系统自带」中对应的系统。
- **已安装的虚拟磁盘**：在「模板库」点击「导入磁盘镜像」，会打开「导入已有系统」窗口。选择文件、填写名称，点击「导入模板」。导入前关闭原虚拟机，启动方式与原虚拟机保持一致。程序会复制到模板库，导入完成后从「我的模板」创建环境。

安装盘和已安装磁盘不同：ISO 不能直接作为已配置好的系统模板导入。

## 使用完以后

先保存系统内的工作，再从 Windows 或 Linux 内正常关机。关闭浏览器标签页不会关闭环境。

如果只想从头测试，可以恢复环境的初始状态；这会丢弃环境中的修改。想保留自己的配置，就先保存为模板。

需要移动程序和全部系统时，请先关闭所有环境和 DeskLab，再按 [发布与镜像加载](distribution.md) 复制完整安装目录。旧便携版继续使用原来的 `.data`；无需为了升级重新安装已有系统。当前成品仅支持 Windows，macOS 版本尚未适配。
