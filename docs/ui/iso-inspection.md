# 安装盘检查 · 0.3.5

创建窗口支持安装目录之外的 ISO。输入路径或选完文件后，等待 300ms 读取 ISO 内部卷标，并对照所选系统类型；文件名不参与系统类型识别。自动安装同时对照固定版本的字节数。检查结果明确区分初步匹配、系统/版本不匹配、无法识别和读取失败。

识别到对应的受支持安装盘时，可保留路径切换到自动安装配置；也可按识别到的系统进入手动安装。未知自定义介质必须勾选确认系统类型，且更改路径、系统、安装模式或重新检查会使确认失效。手动安装的账号与 SSH 配置提示与自动安装分开。

快速检查使用独立、带认证的只读 API，不进入虚拟机操作队列，也不设置全局操作锁。取消窗口或更换文件会中止前端请求，过期结果不能覆盖新选择；读取失败支持重试。

## 服务端约束

创建 API 在分配实例 ID、磁盘目录与密钥之前再次识别并检查介质。自动安装会流式计算 SHA-256，与内置固定源校验值对照，并检查文件在读取期间是否变化。不匹配直接拒绝，不留下空实例。启动时原有安装介质校验仍保留，防止创建后、启动前文件被替换。

卷标只是系统识别依据，不是完整性证明。页面上的“初步匹配”不表示已通过哈希验证。没有可识别卷标的自定义/UDF 介质只能由用户确认类型后手动安装。Windows Server 2022 的现有源未提供固定官方 SHA-256，页面明确提示无法确认完整性；保留原有安装支持，未将本地计算值当作官方校验值。
