# Docker 工作台 · 0.3.1

Docker 页以容器操作为主体。顶部标题与引擎切换、紧凑引擎状态条、资源分类、创建入口和搜索筛选保持固定，只有资源列表滚动。普通虚拟机、模板、设置页保持各自现有布局。

沿用 DeskLab 的钴蓝、浅灰背景与白色工作区，蓝色边线标记当前引擎；使用 Segoe UI / 微软雅黑呈现名称与操作，Cascadia Code / Consolas 呈现镜像标识和端口。标题、引擎状态和列表采用不同密度，不再把每项功能都放进独立大卡片。

引擎资源、磁盘位置、日志、备份和修复统一放入“引擎设置”。操作记录通过顶部时钟图标或列表底部入口打开；执行中的操作仍在页面显示进度入口。外部引擎使用“连接设置”。

资源列表支持名称搜索，容器同时支持镜像、宿主端口搜索，以及全部、运行中、未运行、外部只读筛选。容器按行排列，名称、镜像、来源、访问端口、状态和操作形成固定层级。空列表引导从镜像创建或导入 Compose。
