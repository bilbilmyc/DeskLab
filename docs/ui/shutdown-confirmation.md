# 正常关机确认 · 0.3.6

环境列表上的电源按钮现在先打开确认弹窗，显示当前实例名称，说明正常关机以及磁盘、已保存数据保留。用户点击“确认关机”后才发送该实例的 `/stop` 请求。安装尚未完成时额外提示关机会中断安装。

默认聚焦“取消”，支持取消、Esc 和关闭按钮。请求期间禁用确认与取消，阻止重复提交；失败时保留弹窗和错误提示，可再次确认重试。发送成功后提示等待系统正常退出，避免将请求已发送误报为已关机。强制关闭仍使用独立的断电警告和危险按钮。

后端关机 API 保持现状，这一确认属于用户界面的操作流程。脚本调用 API 和客体系统自身的关机不受此弹窗影响。
