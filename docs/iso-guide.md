# ISO 与系统支持

DeskLab 不分发 Windows/Linux 客体 ISO。首次安装需自己选择安装盘，或从“本机设置 → 系统镜像”下载固定版本。已准备好的模板及其副本不再需要 ISO。完整安装包中的独立 Docker Linux 镜像只供 Docker 引擎使用，不能代替这里的客体安装盘。

## 固定安装盘

自动安装支持以下精确版本与文件；其他版本即使属于同一系统，也不保证适配安装配方。

- Ubuntu 24.04.5 Server：`ubuntu-24.04.5-live-server-amd64.iso`。
- Debian 13.6 Server：`debian-13.6.0-amd64-DVD-1.iso`。
- Rocky Linux 9.8 Server：`Rocky-9.8-x86_64-minimal.iso`。
- Windows 10 Enterprise 22H2 评估版：`Windows_10_Enterprise_22H2_Evaluation_en-us_x64.iso`。
- Windows Server 2022 中文评估版：`Windows_Server_2022_Evaluation_zh-cn_x64.iso`。

目录中另外提供 Ubuntu 24.04.5 Desktop、Debian 13.6 GNOME 和 Rocky 9.8 Workstation 的下载条目，当前需要手动安装或导入已经安装好的磁盘。其他自定义 ISO 也使用手动安装。

下载 URL、字节数、SHA256 和校验出处以 [`server/iso-sources.ts`](../server/iso-sources.ts) 为准；[源说明](iso-sources.md)记录固定版本的核验背景。下载站可能迁移旧版本，访问失败时应核对发布方存档，不要把新版本文件直接重命名成旧版本。

## 文件放在哪里

ISO 可以放在任意可访问的本机目录，例如 `D:\Images\Linux\`。创建时选择完整路径即可，文件不会被上传、搬走或自动复制到安装目录。默认集中扫描目录是应用同级 `iso/`，可在设置中更换；更换扫描目录不改写既有实例记录的路径。

安装未完成前，保持原文件和所在磁盘可用。自动安装完成后程序卸下 ISO；手动安装完成后正常关机并弹出 ISO，或保存为模板。不要直接删除程序的数据盘或模板基盘。

## 选错文件时

选择之后先快速读取 ISO 内部卷标。文件名只是显示名称，不作为系统身份依据。

- 系统类型不匹配：禁用创建，显示“所选系统”和识别结果；可以更换文件或切换安装配置。
- 系统相同但自动安装版本/大小不匹配：更换固定版本，或明确使用手动安装。
- 初步匹配：允许提交，服务端仍会在创建任何实例和磁盘之前做对应检查。
- 无法识别的自定义/UDF 介质：先确认系统类型，再手动安装；需自行配置账号、SSH 和分区。

支持官方校验值的自动安装盘会进行完整 SHA256 对比。检查失败不创建空实例；启动阶段仍会检查介质，防止创建后被替换。Windows Server 2022 当前源没有固定官方 SHA256，只能检查大小并记录本地摘要；页面会明确提示，不能把它称为官方完整性验证。

目录扫描按文件名/大小寻找条目，不等于整盘校验。快速卷标识别也不等于验证文件可信；“初步匹配”和“完整校验通过”是不同阶段。

## 下载、离线使用与备份

下载支持暂停、继续和重试，临时文件位于选定目录的 `.desklab-downloads/`。退出程序会暂停任务；可靠续传取决于下载服务器的 Range/ETag 支持。无网络环境可提前准备 ISO、成品安装包和必要的 Docker 容器镜像。

离线首次安装独立 Docker 需要完整构建的引擎组件；拉取业务容器镜像通常仍需要网络。备份虚拟机必须保留 `data/templates/` 和依赖它的 `data/machines/`，只保存 ISO 不包含已经安装的软件与文件。
